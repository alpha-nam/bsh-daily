Can you help write the game instructions in Chinese?

주제 Topic

상황에 적절한 말: 중국어 게임 설명서 작성을 Lydia에게 부탁하기

요지 Main idea

Matthew의 동아리는 학교 축제에서 윷놀이를 소개하며 게임 설명서를 영어로 썼고 스페인어와 중국어로도 만들고 싶어 합니다. Matthew는 스페인어는 쓸 수 있지만 중국어는 쓸 수 없고, 중국어를 잘하는 Lydia에게 중국어 설명서 작성을 도와 달라고 부탁하려 합니다.

쉬운 설명

Matthew는 중국어를 못 써서, 중국어를 잘하는 Lydia에게 설명서를 같이 써 달라고 부탁해요.

논리 흐름

배경

Matthew와 Lydia는 같은 학교 친구이고, Matthew의 동아리가 축제에서 윷놀이를 소개합니다.

준비 상황

게임 판과 막대를 준비하고 설명서를 영어로 썼으며, 스페인어와 중국어로도 만들고 싶어 합니다.

문제

Matthew는 스페인어는 쓸 수 있지만 중국어는 쓸 수 없습니다.

부탁

중국어를 잘하는 Lydia에게 중국어 설명서 작성을 도와 달라고 부탁하려 합니다.

정답과 오답 분석

① Will you be able to demonstrate how to play the game?게임 방법을 시연해 달라는 부탁은 대본에 없습니다. Matthew가 도움을 구하는 일은 설명서의 중국어 작성입니다(7번).
③ Do you understand the game instructions written in Spanish?6번 Matthew can write the Spanish instructions에서 Matthew는 스페인어 설명서를 직접 쓸 수 있고, Lydia가 스페인어를 이해하는지 묻는 이야기는 없습니다.
④ Could you tell me where to download the Chinese instructions?다운로드 가능 여부는 언급되지 않았으며, Matthew가 하려는 말은 중국어 설명서 작성을 도와 달라는 부탁입니다(7번). 설명서를 내려받을 곳을 묻는 내용은 대본에 없습니다.
⑤ Are you free to help us set up our booth for the school festival?부스를 설치하는 일은 대본에 나오지 않습니다. Matthew가 부탁하려는 것은 중국어 설명서 작성(7번)입니다.
② Can you help write the game instructions in Chinese?6~7번에서 Matthew는 중국어 설명서를 쓸 수 없고, 중국어를 잘하는 Lydia에게 help write the instructions in Chinese를 부탁하려 한다고 했으므로 이 말이 가장 적절합니다.

수업 팁

상황 문제는 ‘누가 무엇을 할 수 없는지(6번)’와 ‘누구에게 무엇을 부탁하려는지(7번)’를 정리해 두면 선지를 쉽게 지울 수 있습니다.

발문 직전 문장 he wants to ask her if ~가 정답에 거의 그대로 나오므로, 이 부분을 놓치지 마세요.
