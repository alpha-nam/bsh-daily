새로운 비밀번호가 설정되면, 녹색 불이 세 번 깜빡일 것이다.

주제 Topic

전자 금고 사용 설명서

요지 Main idea

전자 금고는 처음에 비상 열쇠로 열고, 건전지를 넣은 뒤 비밀번호를 설정해 사용한다. 새 비밀번호가 설정되면 녹색 불이 두 번(세 번이 아님) 깜빡인다.

쉬운 설명

전자 금고의 사용 설명서예요. 처음에는 비상 열쇠로 열고, 건전지를 넣고, 비밀번호를 정해요. 새 비밀번호가 정해지면 녹색 불이 두 번 깜빡여요.

글의 설계도

사용 설명서(처음 열기 → 건전지 → 비밀번호 설정 → 열기 → 주의)

선지의 횟수·색·순서를 해당 항목과 짝지으세요. 특히 불이 깜빡이는 횟수(twice)와 어느 불이 켜지는지가 함정입니다.

숫자 하나가 바뀐 설명서

설명서의 숫자는 하나만 바뀌어도 뜻이 달라져요. 한 번과 두 번, 두 번과 세 번은 서로 다른 신호예요.
