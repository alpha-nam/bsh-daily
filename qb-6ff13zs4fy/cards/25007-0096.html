주제 Topic

컴퓨터 처리에서 실시간이 중요한 경우와 그렇지 않은 경우

요지 Main idea

컴퓨터가 시간에 따라 처리할 때 보통 실시간으로도 작동하기를 원하지만, 녹음된 곡을 다루는 프로듀서에게는 실시간 여부가 결정적이지 않은 반면 무대 위 연주자에게는 실시간 실행이 필수이다.

쉬운 설명

공연할 때는 소리가 바로바로 처리되어야 해요. 하지만 이미 녹음된 노래에 효과를 넣는 일이라면 언제 처리되는지는 상관없어요. 스튜디오의 프로듀서에게는 실시간 여부가 결정적이지 않지만, 무대 위 연주자에게는 실시간 말고는 방법이 없어요.

문장별 분석

1

When computers process in time, we typically want them to also work in real time.

해석

컴퓨터가 시간에 따라(in time) 처리할 때, 우리는 보통 그것이 실시간(real time)으로도 작동하기를 원한다.

쉬운 설명

컴퓨터가 시간에 맞춰 처리할 때 우리는 보통 실시간으로도 작동하길 바라요.

내용 해설

주어진 글: 화제입니다. 시간에 따른 처리와 실시간 작동을 함께 원한다는 상황을 제시합니다.

문법·구문
  • When computers process in time: 시간을 나타내는 접속사 When절입니다.
  • want them to also work: want + 목적어 + to부정사입니다.
2

For example, if you set up a microphone with a reverb effect for a performance, you would like it to work both in time and in real time.

해석

예를 들어, 공연을 위해 리버브 효과가 있는 마이크를 설치한다면, 당신은 그것이 시간에 맞춰서도 실시간으로도 작동하기를 바랄 것이다.

쉬운 설명

공연용 마이크에 리버브를 설치하면, 시간에 맞게도 실시간으로도 작동하길 바랄 거예요.

내용 해설

주어진 글: 예시입니다. 공연용 마이크의 리버브 예에서 실시간 작동이 필요한 상황을 보입니다.

문법·구문
  • would like it to work: like + 목적어 + to부정사로, would like는 완곡하게 바람을 나타냅니다.
3

However, if you just want to add reverb to a prerecorded song, it does not matter when or how fast it happens.

★ (B) 시작However: 공연과 대비되는 녹음된 노래의 경우.! 해석 주의However는 주어진 글의 공연 예(2번)와 대비됩니다.
해석

그러나 미리 녹음된 노래에 리버브를 더하고 싶을 뿐이라면, 그것이 언제 또는 얼마나 빨리 일어나는지는 중요하지 않다.

쉬운 설명

하지만 이미 녹음된 노래에 리버브만 더하려는 거라면, 언제 얼마나 빨리 처리되는지는 상관없어요.

내용 해설

(B) 시작입니다. However로 공연(실시간 필요)과 대비되는 녹음된 노래의 경우를 제시합니다.

문법·구문
  • it does not matter when or how fast it happens: 가주어 it, when or how fast it happens는 의문사절입니다.
4

You may probably prefer that the computer does the processing “faster than real time.”

해석

당신은 컴퓨터가 처리를 ‘실시간보다 빠르게’ 하는 쪽을 아마 선호할 수도 있다.

쉬운 설명

아마 컴퓨터가 ‘실시간보다 빠르게’ 처리하는 쪽을 더 좋아할 수도 있어요.

내용 해설

(B)의 마무리입니다. ‘실시간보다 빠른’ 처리가 다음 (A)의 사례로 이어집니다.

문법·구문
  • prefer that the computer does the processing: that절이 prefer의 목적어입니다.

모범 답안: For a performer on stage, there is no other option than running in real-time mode. 채점 포인트: ① there is no other option than ② than 뒤의 동명사구 running in real-time mode ③ ‘무대 위의 연주자에게는’을 나타내는 표현(For a performer on stage). 의미가 맞는 다른 구조도 허용한다.
