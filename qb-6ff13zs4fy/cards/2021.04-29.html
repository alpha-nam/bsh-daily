주제 Topic

수메르 쐐기 문자의 진화와 문자가 가진 선형 배열의 추상성

요지 Main idea

세계 최초의 복잡한 문자 형태인 수메르 쐐기 문자는 대략 기원전 3500년경 그림 문자에서 표의 문자로, 사물의 묘사에서 추상적 개념의 묘사로 옮겨 가는 진화의 길을 따랐다. 이 문자는 기호를 줄(column)로 배열해 위에서 아래로, 왼쪽에서 오른쪽으로 읽는 선형 체계였는데, 세계는 선형적인 곳이 아니므로 이런 조직화는 추상화의 한 형태였다. 쐐기 문자 이후 등장한 사실상 모든 문자는 분명한 시작과 끝이 있는 행으로 배열되어 왔다. 어법상 틀린 것은 ⑤이며, So ... is this expectation에서 is의 보어 자리이므로 부사 uniformly가 아니라 형용사 uniform이어야 한다.

쉬운 설명

이 글은 아주 오래전 수메르 사람들의 글자 이야기를 해요. 처음엔 사물을 그린 글자였는데 점점 추상적인 생각을 나타내는 글자로 바뀌었대요. 이 글자는 줄을 맞춰 위에서 아래로, 왼쪽에서 오른쪽으로 읽었는데, 현실의 세계는 이렇게 줄을 맞춰 놓여 있지 않아요. 그래서 줄로 배열하는 것도 추상화의 한 형태래요. 6번 문장의 So uniformly is this expectation에서 is 뒤에 올 말은 uniform(형용사)이라서 ⑤가 틀렸어요.

글의 설계도

어법 판단(대명사 that, 과거분사, 재귀대명사, to부정사, 형용사/부사)

밑줄마다 그 말이 문장 안에서 맡은 역할을 먼저 정하세요. ⑤가 들어 있는 6번은 So ... is this expectation ... that ...의 도치 구문입니다. 원래 어순은 this expectation is so uniform that ...이고, 도치되면 보어 so uniform이 is 앞으로 나갑니다. 이 보어는 주어를 설명하는 말이므로 형용사 uniform이어야 합니다.
