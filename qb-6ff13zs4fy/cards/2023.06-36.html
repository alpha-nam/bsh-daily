주제 Topic

물리적 사물이 컴퓨터 코드가 되면서 커지는 소프트웨어 버그와 보안 위험

요지 Main idea

소프트웨어의 복잡성이 커지면서 우리가 의존하는 자동차, 비행기 같은 물리적 물체가 컴퓨터 코드로 바뀌고 있고, 이는 전 지구적 안전과 보안에 직접적인 함의를 가진다. 코드가 커질수록 오류와 버그도 함께 늘고, 이 버그를 이용하는 악성코드 공격이 있으며, 코드가 더 정교해질수록 보안이 훼손되어 사회 전반에 미치는 결과가 커진다.

쉬운 설명

소프트웨어가 점점 복잡해지고 있고, 자동차나 비행기처럼 우리가 기대는 물건들도 컴퓨터 코드로 바뀌고 있어요. 이것은 우리의 안전과 보안에 직접 영향을 줘요. 코드가 커질수록 실수(버그)도 같이 늘어요. 한 연구에 따르면 상용 소프트웨어에는 보통 코드 1,000줄마다 20~30개의 버그가 있어요. 그 버그를 이용하는 악성코드 공격이 있고, 코드가 더 정교해질수록 보안이 약해지고 사회에 미치는 결과도 커져요.

1

The growing complexity of computer software has direct implications for our global safety and security, particularly as the physical objects upon which we depend ― things like cars, airplanes, bridges, tunnels, and implantable medical devices ― transform themselves into computer code.

해석

컴퓨터 소프트웨어의 복잡성이 커지는 것은 우리의 전 지구적 안전과 보안에 직접적인 함의를 가지는데, 특히 우리가 의존하는 물리적 물체들 ― 자동차, 비행기, 다리, 터널, 이식형 의료 기기 같은 것들 ― 이 스스로를 컴퓨터 코드로 바꾸어 가고 있기 때문이다.

쉬운 설명

컴퓨터 소프트웨어가 점점 복잡해지는 것은 우리의 전 세계적 안전과 보안에 직접 영향을 줘요. 특히 우리가 기대는 자동차, 비행기, 다리, 터널, 몸에 넣는 의료 기기 같은 물건들이 컴퓨터 코드로 바뀌고 있어요.

내용 해설

주어진 글(화제 제시)입니다. 소프트웨어의 복잡성과 안전·보안의 관계, 그리고 물리적 물체가 컴퓨터 코드가 되고 있다는 점이 (C)의 Physical things ... information technologies로 이어집니다.

문법·구문
  • the physical objects upon which we depend: ‘전치사 + 관계대명사’가 이끄는 관계절이 objects를 꾸밉니다.
  • things like ... ―: 대시 사이의 삽입으로 objects의 예를 듭니다.
  • transform themselves into ~: 재귀대명사 themselves가 쓰였습니다.

3

Cars are “computers we ride in,” and airplanes are nothing more than “flying Solaris boxes attached to bucketfuls of industrial control systems.”

해석

자동차는 ‘우리가 타고 다니는 컴퓨터’이고, 비행기는 ‘산업 제어 시스템이 잔뜩 연결된 날아다니는 솔라리스 박스’에 지나지 않는다.

쉬운 설명

자동차는 ‘우리가 타고 다니는 컴퓨터’이고, 비행기는 산업 제어 시스템이 잔뜩 붙은 ‘날아다니는 솔라리스 박스’일 뿐이에요.

내용 해설

(C) 끝입니다. 자동차와 비행기를 예로 들어, 물리적 사물이 컴퓨터가 되었다는 점을 구체적으로 보여 줍니다. 이 코드가 4번의 all this code로 이어집니다.

문법·구문
  • nothing more than ~: ‘~에 지나지 않는’입니다.
  • computers we ride in: 목적격 관계대명사가 생략된 관계절이 computers를 꾸밉니다.
  • flying Solaris boxes attached to ...: 과거분사구 attached to ...가 boxes를 뒤에서 꾸밉니다.
4

As all this code grows in size and complexity, so too do the number of errors and software bugs.

★ (A)의 시작all this code는 (C)에서 설명한, 사물이 바뀌어 가는 컴퓨터 코드를 가리키며, 그 코드가 커질수록 오류도 는다고 말한다.! 해석 주의주어진 글에도 computer code가 나오므로 (A)를 바로 이어도 가능해 보입니다. 그러나 (A)의 all this code에서 all this는 이미 많은 코드가 설명된 것처럼 쓴 표현이어서, 사물이 코드가 되어 간다는 내용을 풀어 쓴 (C) 뒤에 오는 것이 더 자연스럽습니다.
해석

이 모든 코드가 크기와 복잡성에서 커짐에 따라, 오류와 소프트웨어 버그의 수도 마찬가지로 늘어난다.

쉬운 설명

이 모든 코드가 크기와 복잡성에서 커지면, 오류와 소프트웨어 버그의 수도 마찬가지로 늘어나요.

내용 해설

(A) 시작입니다. all this code는 (C)에서 말한, 사물이 바뀌어 가는 컴퓨터 코드를 받으며, 코드가 커질수록 오류도 늘어난다는 중심 내용을 엽니다.

문법·구문
  • As ..., so too do ...: ‘~함에 따라 ... 도 마찬가지로’의 뜻이며, so too 뒤에서 do가 주어 앞으로 오는 도치 구문입니다.
  • As: 여기서는 ‘~함에 따라’를 뜻하는 접속사입니다.
5

According to a study by Carnegie Mellon University, commercial software typically has twenty to thirty bugs for every thousand lines of code ― 50 million lines of code means 1 million to 1.5 million potential errors to be exploited.

해석

카네기멜런 대학교의 한 연구에 따르면, 상용 소프트웨어는 통상 코드 1,000줄마다 20~30개의 버그를 가지고 있어, 코드 5천만 줄은 악용될 수 있는 잠재적 오류가 100만~150만 개라는 뜻이다.

쉬운 설명

카네기멜런 대학교의 한 연구에 따르면, 상용 소프트웨어에는 보통 코드 1,000줄마다 버그가 20~30개 있어요. 코드 5천만 줄이면 악용될 수 있는 잠재적 오류가 100만~150만 개라는 뜻이에요.

내용 해설

(A) 끝입니다. 코드가 늘수록 버그가 늘어난다는 점을 연구 수치로 뒷받침하고, 오류가 악용될 수 있다는 점을 6번의 This가 받을 수 있게 남깁니다.

문법·구문
  • for every thousand lines of code: ‘코드 1,000줄마다’를 뜻하는 전치사구입니다.
  • potential errors to be exploited: 수동 to부정사 to be exploited가 errors를 뒤에서 꾸밉니다.
6

This is the basis for all malware attacks that take advantage of these computer bugs to get the code to do something it was not originally intended to do.

★ (B)의 시작This is the basis for all malware attacks that take advantage of these computer bugs는 5번의 악용될 수 있는 오류를 받아 악성코드 공격과 연결한다.! 해석 주의(B)의 This와 these computer bugs는 앞에서 버그가 소개되어 있어야 하므로, 버그와 오류를 말한 (A) 뒤에 오는 것이 더 자연스럽습니다.
해석

이것은 이러한 컴퓨터 버그를 이용하여 코드가 원래 의도되지 않은 일을 하게 만드는 모든 악성코드 공격의 토대이다.

쉬운 설명

이것이, 이런 컴퓨터 버그를 이용해서 코드가 원래 하도록 만들어지지 않은 일을 하게 만드는 모든 악성코드 공격의 바탕이에요.

내용 해설

(B) 시작입니다. This는 5번의 악용될 수 있는 오류가 존재한다는 내용을 받고, these computer bugs는 (A)에서 말한 버그를 가리킵니다.

문법·구문
  • malware attacks that take advantage of ...: 주격 관계대명사절이 attacks를 꾸밉니다.
  • to get the code to do ...: get + 목적어 + to부정사 구조입니다.
  • something it was not originally intended to do: 목적격 관계대명사가 생략된 관계절이 something을 꾸밉니다.
7

As computer code grows more elaborate, software bugs flourish and security suffers, with increasing consequences for society at large.

해석

쉬운 설명

컴퓨터 코드가 더 정교해질수록 소프트웨어 버그는 늘어나고 보안은 나빠져요. 사회 전체에 미치는 결과도 점점 커지고요.

내용 해설

(B) 끝, 결론입니다. 코드가 정교해질수록 버그가 늘고 보안이 훼손되며, 그 결과가 사회 전반으로 커진다고 정리합니다.
