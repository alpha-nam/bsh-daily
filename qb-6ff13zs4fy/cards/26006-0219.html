주제 Topic

적절한 응답: 네트워크 팀에 알리자는 제안에 직접 전화해 보겠다는 응답

요지 Main idea

여자와 남자 모두 인터넷이 되지 않고, 여자는 사무실 네트워크 문제 같으니 네트워크 팀에 알려야 한다고 말합니다. 이에 대한 적절한 응답은 좋은 생각이라며 지금 전화해 확인을 요청하겠다는 말입니다.

쉬운 설명

네트워크 팀에 알리자는 제안에, 그러겠다고 답하는 게 자연스러워요.

문장별 분석

1

W: Mr. Collins, the Internet’s not working for me.

해석

Collins 씨, 저는 인터넷이 안 돼요.

쉬운 설명

자기 쪽 인터넷이 안 된다고 해요.

내용 해설

대화 시작. 문제 상황입니다.

2

How about for you?

해석

당신은 어때요?

쉬운 설명

상대도 그런지 물어요.

3

M: It was working a moment ago, but not any more.

★ 남자도 인터넷 불가It was working a moment ago, but not any more.로 지금은 인터넷이 되지 않음을 알려 줍니다.
해석

조금 전까지는 되었는데, 이제는 안 돼요.

쉬운 설명

좀 전엔 됐지만 지금은 안 된다고 해요.

내용 해설

남자의 인터넷도 지금은 되지 않습니다.

4

W: It seems like there’s an issue with the office network.

해석

사무실 네트워크에 문제가 있는 것 같아요.

쉬운 설명

사무실 네트워크 문제 같다고 해요.

내용 해설

원인에 대한 추측입니다(It seems like).

문법·구문
  • It seems like there’s an issue ~: It seems like + 절 구조입니다.
5

We should let the network team know.

★ 제안We should let the network team know.로 네트워크 팀에 알리자고 제안합니다.
해석

네트워크 팀에 알려야 해요.

쉬운 설명

네트워크 팀에 알리자고 해요.

내용 해설

핵심 단서: 여자가 네트워크 팀에 알릴 것을 제안합니다.

6

M: Good idea.

해석

좋은 생각이에요.

쉬운 설명

좋은 생각이라고 해요.

7

I’ll call them now and ask them to check it out.

해석

제가 지금 전화해서 확인해 달라고 요청할게요.

쉬운 설명

지금 전화해서 확인을 부탁하겠다고 해요.

내용 해설

정답 응답입니다. 제안을 받아들이고 직접 하겠다고 합니다.

논리 흐름

문제 상황

여자가 자신은 인터넷이 되지 않는다며 남자는 어떤지 묻습니다.

상황 확인

남자도 조금 전에는 되었지만 지금은 되지 않는다고 말합니다.

제안

여자가 사무실 네트워크에 문제가 있는 것 같다며 네트워크 팀에 알리자고 합니다.

정답과 오답 분석

① What a relief! They just got done fixing my computer.대본에는 컴퓨터를 수리했다는 내용이 없고, 3번에서 남자도 지금 인터넷이 안 된다고 했습니다. 안도하는 말이 어울리는 상황이 아닙니다.
② That’s good. I’m glad the Internet is working fine now.3번 not any more에서 지금은 인터넷이 되지 않는다고 했으므로, 지금 잘 된다는 말은 대본과 모순됩니다.
④ I don’t think so. The Internet is still working on my computer.3번에서 남자는 인터넷이 조금 전까지 되었지만 이제는 되지 않는다고 했습니다. 지금도 된다는 말은 이와 맞지 않고, 네트워크 팀에 알리자는 5번 제안에 대한 응답도 아닙니다.
⑤ There we go. If the issue comes up again, feel free to contact me.문제가 해결된 뒤에 할 법한 말입니다. 아직 네트워크 팀에 알리지도 않았으므로 맞지 않습니다.
③ Good idea. I’ll call them now and ask them to check it out.여자가 5번에서 네트워크 팀에 알리자고 제안했으므로, 좋은 생각이라며 지금 전화해 확인을 요청하겠다는 응답이 자연스럽습니다.

수업 팁

마지막 화자의 제안(We should ~)에는 수락(Good idea)과 구체적 행동이 이어지는 응답을 찾으세요.

이미 해결된 것처럼 말하는 선지(now working fine, fixing)는 대본의 현재 상황과 맞는지 확인하세요.
