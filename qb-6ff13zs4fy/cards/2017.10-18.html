주제 Topic

GeoWeb 사용자 정보 유출 사고를 알리고 비밀번호 재설정을 권하는 공지

요지 Main idea

필자는 사용자 이름, 이메일 주소, 비밀번호가 권한 없는 제3자에게 취득된 사실이 확인되었다고 알리고, 모든 사용자에게 비밀번호를 가능한 한 빨리 재설정하라고 강력히 권하며 같은 비밀번호를 쓴 다른 사이트에서도 변경하기를 권한다.

쉬운 설명

GeoWeb 사이트에서 사용자들의 이름, 이메일 주소, 비밀번호가 허락 없이 다른 사람의 손에 들어간 일이 확인됐어요. 지금은 비밀번호가 불법으로 쓰였다는 징후는 없지만, 비밀번호를 빨리 바꾸라고 강하게 권해요. 다른 사이트에서 같은 비밀번호를 썼다면 거기서도 바꾸라고 해요.

문장별 분석

1

We are reaching out to you because GeoWeb recently learned about a security incident potentially affecting the accounts of GeoWeb users.

! 해석 주의potentially affecting은 ‘영향을 미칠 수 있는’이며, 사고의 결과가 확정된 것이 아니라 가능성을 말합니다.
해석

저희는 GeoWeb이 최근 GeoWeb 사용자들의 계정에 영향을 미칠 수 있는 보안 사고에 대해 알게 되어 여러분께 연락드립니다.

쉬운 설명

GeoWeb이 사용자 계정에 영향을 줄 수 있는 보안 사고를 알게 되어서 연락한다고 해요.

내용 해설

연락하는 이유입니다. 사용자 계정에 영향을 미칠 수 있는 보안 사고를 알게 되었다는 것이 글의 출발점입니다.

문법·구문
  • potentially affecting the accounts ...: 현재분사구가 a security incident를 뒤에서 꾸밉니다.
  • because ...: 이유를 나타내는 부사절.
2

We promptly hired leading information security experts to investigate this incident and reported the incident to law enforcement.

해석

저희는 이 사고를 조사하기 위해 선도적인 정보 보안 전문가들을 신속히 고용했고, 이 사고를 법 집행 기관에 신고했습니다.

쉬운 설명

정보 보안 전문가들을 빨리 구해서 사고를 조사하게 했고, 법 집행 기관에도 알렸어요.

내용 해설

이미 취한 조치입니다. 전문가를 고용해 조사하고 법 집행 기관에 신고했다는 내용입니다.

문법·구문
  • to investigate this incident: 목적을 나타내는 to부정사.
  • hired ... and reported ...: 두 과거형 동사가 We를 주어로 병렬됩니다.
3

Our investigation has now confirmed that user names, email addresses, and passwords were acquired by an unauthorized third party.

★ 사고 내용사용자 이름, 이메일 주소, 비밀번호가 권한 없는 제3자에게 취득되었다고 확인한다.
해석

저희 조사 결과, 사용자 이름, 이메일 주소, 비밀번호가 권한 없는 제3자에게 취득되었음이 이제 확인되었습니다.

쉬운 설명

조사해 보니 사용자 이름, 이메일 주소, 비밀번호를 허락받지 않은 사람이 가져갔다는 것이 확인됐어요.

내용 해설

사고의 구체적 내용입니다. 유출된 정보가 사용자 이름, 이메일 주소, 비밀번호임을 밝힙니다.

문법·구문
  • has now confirmed that ...: 현재완료. that절이 목적어입니다.
  • were acquired by ...: 수동태.
4

We have no indication at this time that any user passwords have been used illegally, but we strongly recommend that all users reset their passwords as soon as possible.

★ 글의 목적(핵심 문장)모든 사용자에게 비밀번호를 재설정하라고 강력히 권한다.! 해석 주의no indication ... that any user passwords have been used illegally는 ‘불법적으로 사용되었다는 징후가 없다’이지 ‘안전하다’가 아닙니다. 그래서 but 뒤에서 재설정을 강력히 권합니다.
해석

현재로서는 어떤 사용자 비밀번호든 불법적으로 사용되었다는 징후는 없지만, 모든 사용자가 가능한 한 빨리 비밀번호를 재설정할 것을 강력히 권합니다.

쉬운 설명

지금은 비밀번호가 불법으로 쓰였다는 징후가 없지만, 모두 최대한 빨리 비밀번호를 다시 설정하라고 강하게 권해요.

내용 해설

글의 목적(핵심 문장)입니다. but 앞은 현재 확인된 상황, 뒤는 필자가 바라는 행동(비밀번호 재설정)입니다.

문법·구문
  • no indication ... that ...: that절이 indication의 내용을 설명하는 동격절입니다.
  • recommend that all users reset ...: 권고 동사 뒤 that절에 동사원형이 쓰였습니다(should 생략).
  • as soon as possible: 가능한 한 빨리.
5

If you used the same password on any other site, we encourage you to change your password there as well.

★ 추가 권고같은 비밀번호를 쓴 다른 사이트에서도 변경하기를 권한다.
해석

다른 사이트에서 같은 비밀번호를 사용했다면, 그곳에서도 비밀번호를 변경하기를 권합니다.

쉬운 설명

다른 사이트에서도 같은 비밀번호를 썼다면, 거기서도 바꾸라고 권해요.

내용 해설

추가 권고입니다. 다른 사이트에서 같은 비밀번호를 사용한 경우까지 변경을 권합니다.

문법·구문
  • encourage you to change: encourage + 목적어 + to V.
  • If you used ...: 조건을 나타내는 if절.

논리 흐름

사고 알림 (1)

사용자 계정에 영향을 미칠 수 있는 보안 사고를 알게 되어 연락한다.

조치와 확인된 내용 (2-3)

전문가를 고용해 조사하고 신고했으며, 사용자 이름·이메일 주소·비밀번호가 제3자에게 취득된 것이 확인되었다.

사용자에 대한 권고 (4-5)

불법 사용 징후는 없지만 비밀번호를 가능한 한 빨리 재설정하고, 같은 비밀번호를 쓴 다른 사이트에서도 변경하기를 권한다.

열쇠를 잃어버린 집주인의 안내

집 열쇠가 다른 사람 손에 들어간 것이 확인되었다고 알리면서, 아직 집에 들어온 흔적은 없지만 자물쇠를 빨리 바꾸라고 권하는 안내문과 비슷해요.

정답과 오답 분석

② 보안 강화를 위한 웹 사이트 임시 폐쇄를 공지하려고웹 사이트를 임시로 닫는다는 내용은 글에 없습니다. 필자는 사용자에게 reset their passwords를 권합니다.
③ 컴퓨터 보안 프로그램의 업그레이드를 권고하려고보안 프로그램을 업그레이드하라는 말은 나오지 않습니다. 권고하는 것은 비밀번호 재설정과 다른 사이트에서의 변경입니다.
④ 웹 사이트 회원의 주소 업데이트를 요청하려고email addresses는 취득된 정보의 하나로 언급될 뿐, 주소를 갱신해 달라는 요청은 없습니다.
⑤ 네트워크 보안 서비스 업체를 홍보하려고2번 문장의 information security experts는 조사를 위해 고용했다는 조치 설명이며, 특정 업체를 홍보하는 내용이 아닙니다.
① 웹 사이트의 개인 정보 유출에 따른 대처법을 안내하려고3번 문장에서 사용자 이름, 이메일 주소, 비밀번호가 권한 없는 제3자에게 취득되었다고 밝힌 뒤, 4~5번 문장에서 reset their passwords와 change your password there as well로 사용자가 취할 행동을 안내합니다.

수업 팁

공지문에서는 but, however 뒤나 recommend, encourage, ask 같은 요청 동사가 있는 문장에 밑줄을 긋게 하세요.

선지의 ‘임시 폐쇄’, ‘업그레이드’, ‘주소 업데이트’, ‘홍보’가 글에 실제로 나오는지 하나씩 확인하게 하세요.

윗글의 3번 문장에 쓰인 unauthorized의 뜻과 가장 가까운 것은?① without permission② highly skilled③ recently hired④ officially approved⑤ widely known
