쿠키 굽기

주제 Topic

할 일 파악: 여자는 쿠키를 굽는다

요지 Main idea

아들 Daniel이 영화의 밤 준비를 거의 마친 상태에서, 엄마는 쿠키를 굽겠다고 하고 아들에게는 전등을 달라고 말합니다. 여자가 할 일은 쿠키 굽기입니다.

쉬운 설명

아들이 거의 다 준비해 놓았고, 엄마는 간식으로 쿠키를 구워 주기로 해요.

논리 흐름

준비 확인

엄마가 준비 상황을 묻고, 아들은 프로젝터를 이미 테스트했다고 답합니다.

영화와 좌석

볼 영화가 정해졌고, 의자와 담요도 이미 뒷마당에 설치되어 있습니다.

간식

팝콘과 탄산음료는 준비되어 있고, 엄마가 쿠키를 굽겠다고 제안해 아들이 수락합니다.

역할 정리

엄마는 지금 쿠키를 굽겠다고 하고, 아들에게는 전등 다는 것을 잊지 말라고 합니다.

정답과 오답 분석

② 좌석 배치하기10번 I’ve already set up some comfortable chairs and blankets in the backyard.에서 남자가 이미 좌석을 마련했다고 했습니다.
③ 전등 설치하기20번 Don’t forget to put up some lights에서 여자가 전등을 달라고 당부하고, 22번 I’ll do it right away.로 남자가 하겠다고 합니다.
④ 프로젝터 작동 테스트하기3번 I’ve tested the projector에서 남자가 이미 테스트를 마쳤습니다.
⑤ 팝콘과 탄산음료 차려 내기13번 I’ve got popcorn and soda ready.와 14번 I’ll set them out later.에서 남자가 직접 차려 내겠다고 했습니다.
① 쿠키 굽기16번 Should I bake some cookies for everybody?에 남자가 수락하고, 19번 Okay, I’ll get that done now.로 여자가 쿠키를 굽겠다고 합니다.

수업 팁

할 일 문제는 선지 항목이 대화에 모두 나오므로, 각 일을 ‘누가’ 하는지(이미 끝났는지, 남자가 할 것인지, 여자가 할 것인지) 구분해 들으세요.

Should I ~?처럼 말하는 사람이 직접 하겠다고 제안하는 표현과, 이어지는 남자의 수락(That’d be awesome, Mom.)과 여자의 실행 약속(I’ll get that done now)이 정답 단서입니다.
