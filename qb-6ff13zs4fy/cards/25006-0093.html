주제 Topic

적절한 응답: 남은 빵을 나눠 주자는 제안에 대한 동의

요지 Main idea

건물 공사로 가게를 사흘간 닫아야 하는 부부가 남은 빵을 어떻게 할지 이야기하고, 남자가 빵을 나눠 주자고 제안하자 여자가 동의하는 대화입니다.

쉬운 설명

빵이 많이 남았는데 가게를 닫아야 해서, 빵을 나눠 주자는 말에 좋다고 대답해요.

논리 흐름

상황

오늘 빵이 꽤 많이 남았다는 이야기가 나옵니다.

문제

공사로 내일부터 사흘간 가게를 닫아야 해서 남은 빵을 어떻게 할지가 문제가 됩니다.

제안

남자가 빵을 나눠 주자고 제안하며, 필요한 사람이나 자선단체가 있을 거라고 말합니다.

응답

여자가 제안에 동의하며 기부가 좋은 해결책이라고 답합니다.

정답과 오답 분석

① All right. Let’s make more bread next week.남은 빵을 어떻게 할지가 쟁점인데, 이 선지는 다음 주에 빵을 더 만들자고 해서 How about giving it away?라는 제안에 답하지 못합니다.
③ Yes. The building will be completely renovated.대본에는 due to the building construction이라는 말만 있고 건물을 전면 개조한다는 말은 없습니다. 또한 남자의 제안(빵 나눠 주기)과 상관없는 대답입니다.
④ Okay. We can eat this bread tomorrow morning.남자는 giving it away, 즉 남에게 주자고 했는데 이 선지는 직접 먹자는 말이라 제안의 방향이 다릅니다.
⑤ Right. We need to think of ways to increase sales.대화는 팔리지 않고 남은 빵을 처리하는 문제이지 매출을 늘리는 문제가 아닙니다. 매출에 관한 말은 대본에 없습니다.
② Sure. Donating it sounds like a great solution.남자가 How about giving it away?로 빵을 나눠 주자고 했으므로, 승낙하며 기부가 좋은 해결책이라고 답하는 ②가 알맞습니다.

수업 팁

응답 문제는 마지막 발화가 How about ~? 같은 제안일 때 승낙이나 거절로 답하는 선지를 찾으세요.

선지가 대화에 나온 단어(bread, building)를 써도 제안의 내용과 맞지 않으면 오답입니다.
