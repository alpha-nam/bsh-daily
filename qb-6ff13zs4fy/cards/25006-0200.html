주제 Topic

적절한 응답: 숫자를 다시 확인해 주겠다는 제안에 대한 여자의 말

요지 Main idea

여자의 월간 판매 보고서에 실제 판매량과 맞지 않는 것 같은 숫자가 있어 남자가 다시 확인해 주겠다고 제안합니다. 여자는 이 제안을 받아들이는 응답을 해야 합니다.

쉬운 설명

남자가 숫자를 다시 봐 주겠다고 했어요. 여자는 "네, 부탁해요"라고 말하면 돼요.

★ 남자의 제안do you want me to check the numbers again for you?로 확인해 주겠다고 제안하므로 여자는 수락 또는 거절로 답해야 합니다.
해석

쉬운 설명

문법·구문

해석

쉬운 설명

내용 해설

정답 문장. 확인 결과에 따라 곧 끝낼 수 있다는 조건을 덧붙입니다.

문법·구문
  • If ~: 조건절

논리 흐름

진행 상황 확인

남자가 이번 달 판매 확인이 끝났는지 묻고 사장님이 내일 보고 싶어 한다고 알립니다.

문제 발생

여자는 거의 끝났지만 숫자 일부가 실제 판매량과 맞지 않는 것 같다고 말합니다.

제안

남자가 숫자를 다시 확인해 주겠다고 제안합니다.

응답

여자가 제안을 받아들이고, 숫자가 맞으면 곧 끝낼 수 있다고 말합니다.
