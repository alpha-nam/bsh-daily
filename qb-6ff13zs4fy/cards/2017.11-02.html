정답①

Okay. I’ll ask him if he’d like to.

주제 Topic

적절한 응답: 독일 사촌과 이야기해 볼 수 있는지 묻는 남자의 말에 대한 여자의 응답

요지 Main idea

남자는 Emily(여자)의 독일인 사촌이 아직 한국에 있는지 묻고, 며칠 더 있을 거라는 답을 듣습니다. 독일 문화에 관심이 있어 그 사촌과 이야기해 볼 수 있을지 궁금하다고 하므로, 사촌에게 원하는지 물어보겠다는 ① Okay. I’ll ask him if he’d like to.가 알맞은 응답입니다.

쉬운 설명

남자가 독일에서 온 사촌과 이야기해 보고 싶다고 해요. 그러니 사촌에게 이야기하고 싶은지 물어보겠다고 하면 돼요.

1

M: Emily, is your cousin from Germany still in Korea?

★ 대화의 주제is your cousin from Germany still in Korea?로 독일에서 온 사촌이 아직 한국에 있는지 묻습니다.
해석

Emily, 독일에서 온 네 사촌은 아직 한국에 있니?

쉬운 설명

독일에서 온 사촌이 아직 한국에 있는지 물어요.

내용 해설

대화의 시작. 남자가 여자를 Emily라고 부릅니다.

3

He’ll be here for a few more days.

★ 사촌의 체류He’ll be here for a few more days.로 사촌이 며칠 더 한국에 있을 거라고 알려 줍니다.
해석

쉬운 설명

5

M: You know I’m interested in German culture, so I’m wondering if I could talk with him.

★ 마지막 발화I’m wondering if I could talk with him.으로 사촌과 이야기해 볼 수 있을지 묻습니다. 응답은 이 부탁에 대한 대답이어야 합니다.
해석

내가 독일 문화에 관심이 있는 거 알잖아. 그래서 그와 이야기해 볼 수 있을지 궁금해.

쉬운 설명

독일 문화에 관심이 있어서 사촌과 이야기해 볼 수 있을지 궁금하다고 해요.

내용 해설

마지막 발화(남자). 부탁하는 말입니다.

문법·구문
  • I’m wondering if I could ~: ‘~할 수 있을지 궁금합니다’라는 공손한 부탁
  • if: ‘~인지’를 뜻하는 명사절 접속사
6

W: Okay. I’ll ask him if he’d like to.

해석

알았어. 그가 원하는지 내가 물어볼게.

쉬운 설명

알겠다고 하면서 사촌에게 원하는지 물어보겠다고 해요.

내용 해설

정답 응답. 부탁을 받아들이며 사촌의 의사를 물어보겠다고 합니다.

문법·구문
  • if he’d like to: to 뒤에 talk with you가 생략된 형태

논리 흐름

확인

남자가 독일에서 온 여자의 사촌이 아직 한국에 있는지 묻고, 여자는 며칠 더 있을 거라고 답합니다.

이유 질문

여자가 왜 묻는지 되묻습니다.

부탁

남자는 독일 문화에 관심이 있어서 사촌과 이야기해 볼 수 있을지 궁금하다고 합니다.

응답

여자는 이 부탁에 대한 대답을 해야 하며, 사촌에게 물어보겠다고 하는 것이 알맞습니다.

정답과 오답 분석

② Too bad. He went back yesterday.여자는 사촌이 며칠 더 있을 거라고 이미 말했습니다(3번). 어제 돌아갔다는 말은 이와 어긋납니다.
③ Exactly. I plan to visit Korea later.나중에 한국을 방문할 계획이라는 말은 사촌과 이야기해 볼 수 있을지 묻는 남자의 부탁(5번)에 답하지 않습니다.
④ No. I want to stay longer if possible.더 머무는 사람은 여자의 사촌입니다(3번). 여자가 자신이 더 머물고 싶다고 말하는 것은 상황에 맞지 않고, 남자의 부탁에 답하지도 않습니다.
⑤ Right. We haven’t been to Germany.남자의 부탁은 사촌과 이야기해 볼 수 있는지이며(5번), 독일에 가 본 적이 있는지와는 관계가 없습니다.
① Okay. I’ll ask him if he’d like to.5번에서 남자가 사촌과 이야기해 볼 수 있을지 묻고 있으므로, 이를 받아들이며 사촌의 의사를 물어보겠다고 하는 응답이 알맞습니다.

수업 팁

마지막 발화가 I’m wondering if I could ~처럼 완곡한 부탁이면, 받아들이거나 거절하는 말을 고르세요.

대화에 나온 사실(며칠 더 머문다)과 어긋나는 선지는 먼저 지울 수 있습니다.
