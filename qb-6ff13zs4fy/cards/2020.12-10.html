요지 Main idea

표(Reusable Straw Sets)의 값은 A 대나무 $5.99·7인치·케이스 없음, B 유리 $6.99·7인치·케이스 있음, C 유리 $7.99·8인치·케이스 없음, D 실리콘 $8.99·8인치·케이스 있음, E 스테인리스 $11.99·9인치·케이스 있음입니다. 대나무(A), 10달러 초과(E), 길이 7인치(B), 케이스 없음(C)을 차례로 제외하면 D가 남습니다.

논리 흐름

재질

대나무는 빨리 마르지 않을까 걱정되어 대나무인 A를 제외합니다.

가격

10달러를 넘기고 싶지 않다고 하므로 $11.99인 E를 제외합니다.

길이

8인치나 9인치가 좋다고 하므로 7인치인 B를 제외하고 C와 D가 남습니다.

휴대용 케이스

케이스가 있으면 유용하다고 하므로 케이스가 없는 C를 제외하고 D를 주문합니다.

정답과 오답 분석

① A (대나무 / $5.99 / 7인치 / 케이스 ×)대나무는 9번에서 빨리 마르지 않을까 걱정된다고 해서 제외됩니다. 7인치라서 16번의 8~9인치 조건에도 맞지 않고, 케이스도 없습니다.
② B (유리 / $6.99 / 7인치 / 케이스 ○)가격과 케이스는 조건에 맞지만, 길이가 7인치라서 16번 eight or nine inches should be perfect에서 말한 8~9인치가 아닙니다.
③ C (유리 / $7.99 / 8인치 / 케이스 ×)가격과 길이는 조건에 맞아 17번의 남은 두 개 중 하나지만, 케이스가 없습니다(×). 18번에서 케이스가 유용하다고 했으므로 C는 제외됩니다.
⑤ E (스테인리스 스틸 / $11.99 / 9인치 / 케이스 ○)길이와 케이스는 조건에 맞지만, 가격이 $11.99로 13번 I don’t want to spend more than $10의 10달러를 넘습니다.
④ D (실리콘 / $8.99 / 8인치 / 케이스 ○)대나무가 아니고(9번), 가격 $8.99가 10달러를 넘지 않으며(13번), 길이 8인치가 조건 8~9인치에 맞고(16번), 휴대용 케이스도 있어(18번) 모든 조건을 만족하는 것은 D입니다.

수업 팁

도표 문제는 표를 먼저 훑어 열(재질·가격·길이·케이스)을 확인한 뒤, 대화에서 나오는 조건 순서대로 후보를 지워 갑니다. 이 대화는 재질(대나무 제외) → 가격(10달러 초과 제외) → 길이(8~9인치) → 케이스 순서입니다.

표에는 숫자와 기호(○, ×)가 많으므로 ‘넘게(more than)’, ‘이상·이하’ 같은 기준 표현을 정확히 듣습니다. more than $10은 10달러를 넘는 것을 피하겠다는 뜻이므로 $11.99인 E가 제외됩니다.
