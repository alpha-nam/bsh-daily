요지 Main idea

2023년 유로 지역 7개국의 GDP와 국가 부채(단위: 십억 유로)를 막대로 비교한 도표이다. 막대 옆에 적힌 값은 (GDP / 국가 부채) 순으로 독일 4,457.37 / 2,648.99, 프랑스 3,031.78 / 3,101.2, 이탈리아 2,255.5 / 2,862.81, 스페인 1,581.15 / 1,570.96, 아일랜드 545.79 / 218.62, 그리스 238.28 / 371.93, 포르투갈 287.42 / 263.08이다. 아일랜드의 GDP는 545.79로 500을 넘으므로, 아일랜드·그리스·포르투갈이 각각 GDP와 국가 부채 수치가 모두 5,000억 유로(500십억 유로) 미만이라는 ⑤가 도표와 일치하지 않는다.

쉬운 설명

일곱 나라의 GDP와 국가 부채를 막대로 보여 주는 그래프예요. 막대 끝에 숫자가 적혀 있어서, 선지에 나온 순위나 차이, 기준 숫자를 하나씩 찾아 맞춰 보면 돼요. 더하거나 빼야 하는 말은 직접 계산해 보면 어긋나는 문장을 찾을 수 있어요.
