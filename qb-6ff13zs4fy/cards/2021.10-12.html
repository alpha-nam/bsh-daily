주제 Topic

적절한 응답: 집에 여분의 전구가 없다는 말에 대한 여자의 응답

요지 Main idea

욕실 전구가 깜빡이자 남자가 전구를 갈 때가 된 것 같다고 말합니다. 여자가 여분의 전구가 없냐고 묻지만, 남자는 여분을 차고 전구를 갈 때 썼고 집에는 하나도 없다고 합니다. 그러므로 여자는 상황을 이해하고 새 전구를 구하러 가겠다고 답하는 것이 자연스럽습니다.

문장별 분석

1

M: Honey, the bathroom light is blinking now.

해석

자기야, 지금 욕실 불이 깜빡이고 있어.

쉬운 설명

욕실 불이 깜빡인다고 해요.

내용 해설

‘Honey’는 친근하게 부르는 호칭입니다.

2

I guess it’s time to change the light bulb.

★ 상황it’s time to change the light bulb: 욕실 전구를 갈아야 하는 상황입니다.
해석

전구를 갈 때가 된 것 같아.

쉬운 설명

전구를 갈 때가 된 것 같다고 해요.

문법·구문
  • it’s time to ~: ‘~할 때다’
3

W: You’re right.

해석

맞아.

쉬운 설명

맞다고 해요.

4

Don’t we have an extra light bulb?

해석

여분의 전구가 없어?

쉬운 설명

여분의 전구가 없냐고 물어요.

문법·구문
  • 부정 의문문(Don’t we have ~?): ‘~이 있지 않아?’
5

M: Well, I used it when I replaced the light bulb in the garage.

★ 원인I used it when I replaced the light bulb in the garage.: 여분의 전구는 차고 전구를 갈 때 썼습니다.
해석

음, 그건 차고 전구를 갈 때 썼어.

쉬운 설명

여분은 차고 전구를 갈 때 썼다고 해요.

내용 해설

여분의 전구는 차고 전구를 교체할 때 이미 썼습니다.

6

We don’t have any at home.

★ 남자의 마지막 말We don’t have any at home.: 집에 여분의 전구가 없습니다.
해석

집에는 하나도 없어.

쉬운 설명

집에 전구가 하나도 없다고 해요.

내용 해설

남자의 마지막 말입니다. 집에 전구가 없습니다.

7

W: Oh, I see.

해석

아, 그렇구나.

쉬운 설명

알겠다고 해요.

내용 해설

정답 응답 (앞부분). 상황을 이해합니다.

8

Then I’ll go get some new ones now.

해석

그럼 지금 가서 새 걸 사 올게.

쉬운 설명

지금 가서 새 전구를 가져오겠다고 해요.

내용 해설

정답 응답 (뒷부분). 새 전구를 구하러 가겠다고 합니다.

문법·구문
  • go get ~: ‘가서 ~을 가져오다’
  • ones: 앞의 light bulb를 대신하는 대명사

논리 흐름

문제 상황

욕실 불이 깜빡여 전구를 갈 때가 된 것 같다고 합니다(1~2번).

여분 확인

여자가 여분의 전구가 없냐고 묻습니다(4번).

남자의 답

여분은 차고 전구를 갈 때 썼고 집에는 하나도 없다고 합니다(5~6번).

여자의 응답

상황을 이해하고 새 전구를 사러 가겠다고 하는 것이 자연스럽습니다(7~8번).

정답과 오답 분석

① Be careful. You might get an electric shock.조심하라며 감전 가능성을 경고하는 말입니다. 남자의 마지막 말은 집에 전구가 하나도 없다는 것이므로(6번) 이에 대한 응답으로 맞지 않습니다.
③ Great. The bathroom is much brighter than before.아직 전구를 갈지 못했고 욕실 불은 깜빡이는 상태입니다(1~2번). 욕실이 더 밝아졌다는 말은 상황과 맞지 않습니다.
④ All right. I’ll replace the garage light bulb right now.차고 전구는 이미 새것으로 교체되었습니다(5번). 욕실에 쓸 전구가 없다는 말에 차고 전구를 교체하겠다는 응답은 맞지 않습니다.
⑤ Never mind. I’ll come back when the items are in stock.물건이 입고되면 다시 오겠다는 말은 가게에서 재고가 없을 때 어울립니다. 이 대화는 집 안에서 이루어지고 있습니다.
② Oh, I see. Then I’ll go get some new ones now.남자가 We don’t have any at home.(6번)이라고 했으므로, 상황을 이해하고 새 전구를 구하러 가겠다고 하는 응답이 자연스럽습니다.

수업 팁

응답 문제는 마지막 말이 알려 주는 ‘새로운 사실’(집에 전구가 없다)에 어울리는 반응을 고르세요.

선지에 대본에 나온 단어(garage, light bulb)가 들어 있어도 상황과 맞는지 확인하세요.
