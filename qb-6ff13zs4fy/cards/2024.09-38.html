7번 문장(To be successful, ...) 뒤

주제 Topic

로봇이 목표 지향적 행동을 하려면 자신과 환경 속의 다른 것을 구별할 수 있어야 한다

요지 Main idea

지각하고 행동하도록 설계된 로봇에게는 자신을 환경 속의 다른 실재물과 구별하는 능력이 근본적이며, 그런 능력이 없으면 목표 지향적 행동이 가능하지 않다. 블록을 쌓는 단순한 과제조차 로봇이 블록의 탐지와 자신의 팔의 탐지를 구별하는 내장 시스템을 갖출 것을 요구하며, 그렇지 않으면 로봇은 블록이 아니라 자기 자신을 끝없이 쫓을지도 모른다.

쉬운 설명

로봇이 일을 하려면 ‘나’와 ‘내 밖의 것’을 구별할 줄 알아야 해요. 블록을 쌓는 로봇도 블록이 보내는 신호와 자기 팔이 보내는 신호를 가려낼 수 있어야 해요. 그렇지 않으면 블록이 아니라 자기 자신을 끝없이 쫓아다닐지도 몰라요.

주장(구별 능력의 중요성) → 예시(블록 쌓는 로봇) → 필요한 시스템 → (주어진 문장: 그렇지 않을 때) → 결과

주어진 문장의 If not은 바로 앞에서 어떤 조건이 말해져야 의미가 이어집니다. 7번의 To be successful, your machine will have to have some built-in system이 그 조건이고, 이어지는 8번의 circular, self-centered acts가 주어진 문장의 chase itself를 구체화합니다. 표지 ①~⑤는 각각 3~7번 문장 뒤에 있습니다.

8

Your robot would engage in circular, self-centered acts that would drive it away from the target or external goal.

★ 정답 뒤 문장circular, self-centered acts는 주어진 문장의 chase itself를 구체화한다.
해석

당신의 로봇은 원을 그리는 자기 중심적인 행동에 빠져, 그것이 로봇을 목표 또는 외부의 목적으로부터 멀어지게 할 것이다.

쉬운 설명

로봇은 제자리를 도는 듯한 자기 중심적인 행동에 빠지고, 그 행동은 로봇을 목표나 바깥의 목적에서 멀어지게 만들 거예요.

내용 해설

결과입니다. 주어진 문장의 chase itself를 circular, self-centered acts로 구체화합니다.

문법·구문
  • engage in ~: ‘~에 빠지다, 참여하다’.
  • acts that would drive it away from ...: 주격 관계대명사절이 acts를 꾸미고, it은 Your robot을 가리킵니다.

논리 흐름

주장 (2-3)

자신을 환경 속의 다른 것과 구별하는 능력은 근본적이며, 없으면 목표 지향적 행동이 불가능하다.

예시 (4-6)

블록을 찾아 쌓는 로봇은 자신의 장치에서 오는 자극과 블록에서 오는 자극을 구별해야 하고, 인공 눈과 팔을 갖춘다고 가정한다.

조건 (7)

성공하려면 블록의 탐지와 자신의 팔의 탐지를 구별하는 내장 시스템이 필요하다.

그렇지 않을 때 (주어진 문장 1, 8)

그렇지 않으면 로봇은 블록이 아니라 자기 자신을 쫓으며 목표에서 멀어진다.

거울 속의 나를 쫓는 강아지

거울에 비친 모습이 자기 자신인 줄 모르는 강아지가 있다면, 장난감 대신 거울 속의 모습만 쫓아 빙글빙글 돌 거예요.

정답과 오답 분석

① 3번 문장(Without such an ability, ...) 뒤①에 넣으면 3번이 이미 ‘그런 능력이 없으면 목표 지향적 행동이 불가능하다’고 부정적인 경우를 말했으므로 If not이 받을 긍정의 조건이 분명하지 않습니다. 또 3번에서 바로 4번 Imagine that you have to build a robot의 예시로 이어지는 흐름이 끊깁니다.
② 4번 문장(Imagine that you have to build a robot ...) 뒤②에 넣으면 If not이 ‘로봇을 만들어야 한다고 상상하라’라는 문장을 받게 되어 무엇이 ‘그렇지 않다’는 것인지 분명하지 않습니다. 또 5번의 Even this simple task가 4번의 과제를 바로 받는 연결이 약해집니다.
③ 5번 문장(Even this simple task would require ...) 뒤③에 넣으면 If not이 5번의 be able to discriminate에 걸려 읽힐 수 있어 그럴듯합니다. 그러나 그러면 6번의 인공 눈·팔 설정과 7번 To be successful, your machine will have to have some built-in system이 주어진 문장 뒤로 밀리고, 8번의 circular, self-centered acts가 앞의 chase itself와 떨어져 ⑤보다 연결이 약합니다.
④ 6번 문장(Suppose that you equip your robot ...) 뒤④에 넣으면 If not이 ‘인공 눈과 팔을 장착한다고 가정하라’는 문장을 받아 장착하지 않은 경우처럼 읽힙니다. 이 경우 7번의 To be successful이 6번의 설정을 바로 받는 연결도 약해집니다.
⑤ 7번 문장(To be successful, ...) 뒤7번에서 성공하려면 블록의 탐지와 자신의 팔의 탐지를 구별하는 내장 시스템이 필요하다고 했으므로, If not은 ‘그런 시스템이 없다면’으로 자연스럽게 읽힙니다. 이어지는 8번의 circular, self-centered acts가 주어진 문장의 chase itself를 구체화합니다.

수업 팁

주어진 문장의 If not이 받는 조건을 먼저 찾게 하세요. 7번의 To be successful, your machine will have to have some built-in system이 그 조건입니다.

③은 If not이 5번의 be able to discriminate에 걸려 읽혀 함정입니다. 6번의 인공 눈·팔 설정과 8번의 circular, self-centered acts와의 연결까지 확인하게 하세요.
