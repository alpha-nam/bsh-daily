수영 캠프 참가 학생 증가로 수영장 추가 대여 가능 여부를 묻는 편지

요지 Main idea

수영 코치인 Nelson Perkins는 이미 수영장 한 곳을 예약했지만, 캠프에 예상보다 30명 더 많은 학생이 오게 되어 수영장이 하나 더 필요하다며, 웹사이트에 나온 다른 수영장 두 곳의 추가 대여가 가능한지 문의한다.

쉬운 설명

수영 캠프를 여는 선생님이 수영장을 한 곳 빌려 두었어요. 그런데 예상보다 학생이 30명 더 오게 되어서 수영장이 하나 더 필요해요. 그래서 수영장을 더 빌릴 수 있는지 물어보는 편지를 썼어요.

논리 흐름

소개 (1)

글쓴이가 자신이 교사이자 수영 코치임을 밝히며 인사한다.

상황 (2-3)

수영장 한 곳을 예약했는데 예상보다 30명 더 많은 학생이 오게 되어 하나가 더 필요하다.

요청 (4-5)

웹사이트에 나온 다른 수영장 두 곳을 언급하며 추가 대여가 가능한지 묻는다.

맺음 (6-7)

감사 인사와 서명으로 마친다.

식당 자리 추가 문의

예약해 둔 식당에 갑자기 일행이 예상보다 늘어서, 자리를 더 마련할 수 있는지 전화로 묻는 것과 비슷해요.

정답과 오답 분석

① 수영 캠프 참가 날짜를 변경하려고캠프 날짜를 바꾸고 싶다는 말은 글에 없습니다. 3번에서 참가 학생이 예상보다 30명 더 많다는 점을 말하고 we need one more swimming pool이라며 수영장이 더 필요하다고 합니다.
② 수영장 수용 가능 인원을 확인하려고수용 인원을 묻는 문장은 없습니다. 3번의 thirty more students는 수영장이 하나 더 필요한 이유로 제시된 것이고, 5번에서 묻는 것은 추가 대여가 가능한지입니다.
③ 수영 캠프 등록 방법에 대해 알아보려고등록 방법을 묻는 내용이 없습니다. 2번에서 글쓴이는 이미 수영장 한 곳을 예약했고(I made a reservation), 캠프 참가자를 모집하는 것이 아니라 수영장을 하나 더 빌리는 것을 문의합니다.
⑤ 수영장 대여 취소에 따른 환불을 요청하려고예약을 취소했다는 말이나 환불을 요구하는 말이 없습니다. 오히려 수영장이 하나 더 필요해서(3번) 추가 대여를 문의합니다.
④ 수영장 추가 대여 가능 여부를 문의하려고3번에서 예상보다 30명 더 많은 학생이 오게 되어 we need one more swimming pool이라고 하고, 5번에서 Please let me know if an additional rental would be possible.라고 묻습니다. 글의 목적은 수영장을 추가로 대여할 수 있는지 문의하는 것입니다.

수업 팁

목적 문제는 편지에서 부탁·문의를 직접 말하는 문장(Please let me know if ~, 5번)을 먼저 찾게 하세요.

3번의 However처럼 상황이 바뀌는 연결어 뒤에 글을 쓰게 된 이유가 나오는 경우가 많습니다. 이 이유와 5번의 요청이 이어지는지 확인하게 하세요.
