주제 Topic

Smart Pet Feeder 사용 안내: 스위치 버튼, 설정 버튼, 상태 표시등, 네트워크 표시등

요지 Main idea

Smart Pet Feeder 사용 안내문이다. 스위치 버튼은 부드럽게 눌러 덮개를 열고, 설정 버튼은 모터가 회전할 때 누르면 안 되며, 한 번 빠르게 누르면 사료가 한 몫 나오고 5초 동안 누르면 기기가 재설정된다. 상태 표시등은 켜짐이 전원 켜짐, 꺼짐이 전원 꺼짐, 깜빡임이 오류를 뜻하므로, 문제가 있을 때 계속 켜져 있다는 ③은 안내문과 일치하지 않는다. 네트워크 표시등은 켜짐이 연결 중, 꺼짐이 연결 안 됨, 느린 깜빡임이 연결 대기, 빠른 깜빡임이 연결됨이다.

쉬운 설명

자동으로 사료를 주는 기기의 사용 설명서예요. 버튼마다, 표시등마다 어떻게 쓰는지 적혀 있어요. 상태 표시등은 불이 켜져 있으면 전원이 켜진 것이고, 깜빡이면 오류예요. 문제가 있을 때 ‘계속 켜져 있다’는 말은 안내문과 달라요.

안내문 내용 일치

윗글 안내문의 내용과 일치하는 것은?① 스위치 버튼은 세게 눌러야 덮개가 열린다.② 설정 버튼을 한 번 빠르게 누르면 기기가 재설정된다.③ 상태 표시등이 꺼져 있으면 전원이 꺼진 상태이다.④ 네트워크 표시등이 켜져 있으면 네트워크에 연결되지 않은 상태이다.⑤ 네트워크 표시등이 느리게 깜빡이면 네트워크에 연결된 상태이다.

정답 ③ 9번 문장의 Light off: power off와 일치하므로 ③이 맞습니다. ①은 Press gently와 어긋나고, ②는 한 번 빠르게 누르면 사료 한 몫이 나오고 재설정은 5초 동안 누르는 것이며, ④는 켜짐이 연결 중이고 꺼짐이 연결되지 않음이므로 틀리고, ⑤는 느린 깜빡임이 연결을 기다리는 상태이므로 틀립니다.

안내문 표시 읽기
