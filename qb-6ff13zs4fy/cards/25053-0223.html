담화 내용 일치: Run for Hope, 개인 차량 주차는 허용되지 않는다

요지 Main idea

논리 흐름

행사 소개

건강을 증진하고 좋은 일을 후원하는 Run for Hope를 소개하고 장소와 시간을 알립니다.

목적과 등록비

암에 걸린 어린이를 위한 기금 마련이 목적이며 등록비는 1인당 $5입니다.

등록과 코스

온라인으로만 등록할 수 있고 세 개의 코스 중에서 선택합니다.

유의 사항

개인 차량 주차는 허용되지 않으니 대중교통을 이용하고 일찍 도착하라고 당부합니다.

내용 일치 문제는 선지의 수치($5, three)와 한정 표현(only)을 대본과 하나씩 대조하세요.
