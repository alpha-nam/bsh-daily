논리 흐름

세트 가격 확인

작은 세트는 $30, 큰 세트는 $40이고 여자는 큰 세트를 삽니다.

가방 가격

가방은 원래 $20이지만 10% 할인($2)으로 $18입니다.

포장비

함께 선물 포장하는 데 추가 $5가 듭니다.

합계

$40 + $18 + $5 = $63입니다.

정답과 오답 분석

① $53$53은 작은 세트($30) + $18 + $5일 때의 합계입니다. 여자는 I’ll take a large set.이라고 했으므로 세트값은 $40입니다.
② $55세트 $40 + 가방 $18 + 포장비 $5 = $63보다 $8 적습니다. 세 항목이 모두 대본에서 결제 대상으로 나옵니다.
③ $60$40 + $18 + $5 = $63보다 $3 적습니다. an extra $5 fee for gift wrapping에 여자가 That’s fine.이라고 답했으므로 포장비 $5도 냅니다.
⑤ $65$40 + $20 + $5 = $65는 가방의 10% 할인($2)을 반영하지 않은 값입니다. it’s on sale for 10% off이므로 가방은 $18입니다.
④ $63큰 세트 $40 + 10% 할인된 가방 $18($20 × 0.9) + 포장비 $5 = $63입니다.

수업 팁

할인율이 나오면 원래 가격에서 할인액을 먼저 계산해 두고($20의 10% = $2), 추가 요금은 마지막에 더하세요.

extra, on sale, off 같은 표현은 금액이 바뀌는 신호입니다.
