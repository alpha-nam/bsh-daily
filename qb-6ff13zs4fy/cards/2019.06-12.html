주제 Topic

도표 파악: 가격·재질·색·사은품 조건으로 고른 그림 액자(모델 D)

요지 Main idea

두 사람은 $40 미만, 플라스틱이 아닌 재질, 흰색이 아닌 색, 사진 자석 사은품의 조건으로 고릅니다. $40 미만은 A, B, D, E이고, 플라스틱인 E를 제외하면 A, B, D입니다. 흰색인 B를 제외하면 A, D가 남고, 사진 자석이 사은품인 모델은 D입니다. 따라서 주문할 액자는 ④ 모델 D입니다.

쉬운 설명

40달러보다 싸고, 플라스틱이 아니고, 흰색이 아니고, 사은품이 사진 자석인 액자를 찾으면 모델 D만 남아요.

논리 흐름

가격

$40 미만이므로 A($30), B($33), D($35), E($28)만 남고 C($42)는 제외됩니다(6~9번).

재질

플라스틱이 아니어야 하므로 E(Plastic)가 제외되어 A, B, D가 남습니다(11~16번).

색

흰색은 제외하므로 B(White)가 빠지고 A(Gold), D(Brown)가 남습니다(18~22번).

사은품

사진 자석을 고르므로 사은품이 Picture Magnet인 D가 정답입니다(24~25번).

정답과 오답 분석

① A ($30 / Paper / Gold / Picture Key Ring)가격, 재질, 색은 조건에 맞지만 사은품이 Picture Key Ring이어서 사진 자석을 고른 것(25번)과 맞지 않습니다.
② B ($33 / Ceramic / White / Picture Key Ring)흰색이어서 18번 not white와 맞지 않습니다. 사은품도 Picture Key Ring입니다.
③ C ($42 / Aluminum / Silver / Picture Magnet)가격이 $42로 $40을 넘으므로 under $40(9번)과 맞지 않습니다.
⑤ E ($28 / Plastic / Blue / Picture Key Ring)재질이 Plastic이어서 플라스틱이 아닌 모델을 고른다는 조건(16번)과 맞지 않습니다.
④ D ($35 / Bamboo / Brown / Picture Magnet)$35로 $40 미만이고, 재질은 Bamboo(플라스틱 아님), 색은 Brown(흰색 아님), 사은품은 Picture Magnet이어서 네 조건을 모두 충족합니다.

수업 팁

도표 문제는 조건이 나오는 순서대로 표에서 탈락시키며 후보를 줄입니다. 가격 → 재질 → 색 → 사은품 순서로 지웁니다.

under $40은 $40 미만입니다. 정확히 $40인 값이 있는지도 확인하세요(이 표에는 없습니다).
