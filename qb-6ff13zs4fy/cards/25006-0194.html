주제 Topic

할 일 파악: 여자는 메인 서버 바이러스 검사를 한다

요지 Main idea

마케팅 부서의 네트워크 문제를 두고 남자는 부서를 직접 가 보고, 여자는 메인 서버의 바이러스를 검사하기로 합니다.

쉬운 설명

남자는 마케팅 부서에 가서 살펴보고, 여자는 중심 서버에 바이러스가 있는지 검사하기로 했어요.

원인 추정

역할 분담

당부

여자가 남자에게 파일 백업을 먼저 하라고 당부합니다.

정답과 오답 분석

① 모든 파일 백업하기18번 don’t forget to back up all the files first는 여자가 남자에게 한 당부이고, 20번 I’ll make sure to do it.에서 남자가 하겠다고 답합니다. 여자의 할 일이 아닙니다.
② 마케팅 부서 방문하기12번 I’ll head over to the marketing department에서 마케팅 부서에 가는 사람은 남자입니다.
③ 네트워크 오류 신고하기3번에서 여자는 IT 부서 시스템으로 서비스 요청을 받은 쪽이며, 직접 신고하겠다는 말은 없습니다.
⑤ 바이러스 예방 프로그램 설치하기바이러스 예방 프로그램을 설치한다는 말은 대본에 없습니다. 바이러스와 관련해 나오는 일은 서버를 검사하는 것(scanning the main server)입니다.
④ 메인 서버 바이러스 검사하기14번 I’ll take care of scanning the main server for viruses.에서 여자가 직접 맡겠다고 합니다.

수업 팁

할 일 문제는 누가 무엇을 하는지 구분해야 합니다. I’ll, I’ll take care of처럼 화자 본인이 하겠다는 표현을 찾으세요.

마지막의 당부(don’t forget to)는 상대에게 시킨 일일 수 있으니 주어를 확인하세요.
