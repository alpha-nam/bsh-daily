주제 Topic

숫자 정보 파악: 맞춤 케이크 주문 금액 (기본 $30 + 모양 $10 + 장식 2개 $10 = $50)

요지 Main idea

맞춤 케이크를 주문하는 대화입니다. 기본 가격 $30에 농구공 모양 추가 $10, 장식 2개($5씩) $10이 더해지고, 여자가 직접 가져가므로 배송비 $5는 없습니다. 지불할 금액은 $50입니다.

논리 흐름

기본 가격

케이크는 $30부터 시작합니다(4번).

추가 항목

농구공 모양은 $10 추가(7번), 장식은 하나에 $5이고 두 개를 추가합니다(10~12번).

배송 여부

배송은 $5이지만 여자가 직접 가져가겠다고 합니다(18~19번).

계산

$30 + $10 + ($5 × 2) = $50입니다.

정답과 오답 분석

① $35기본 $30, 모양 추가 $10, 장식 2개 $10이 모두 들어가므로 합계는 $50입니다. $35는 이 합계와 맞지 않습니다.
② $40기본 $30에 모양 추가 $10만 더한 값입니다. 12번에서 장식 2개($5 × 2 = $10)가 더해지므로 합계는 $50입니다.
③ $45합계는 $30 + $10 + $10 = $50이고, $45가 되는 항목 조합은 대본에 없습니다.
⑤ $55$50에 배송비 $5를 더한 값입니다. 그러나 19번에서 여자가 직접 가져가겠다고 했으므로 배송비는 들지 않습니다.
④ $50기본 $30, 농구공 모양 추가 $10, 장식 2개 $10을 더해 $50이고, 직접 가져가므로 배송비 $5는 없습니다.

수업 팁

숫자 문제는 기본 가격, 추가 금액, 개수를 하나씩 적어 가며 들으세요. each가 나오면 개수를 곱해야 합니다.

마지막에 배송 여부처럼 금액이 더해질 수 있는 항목을 선택했는지 꼭 확인하세요. 여기서는 직접 가져가므로 $5가 빠집니다.
