정답①

is simply no longer presented

주제 Topic

컴퓨터 보안의 딜레마를 사용자 교육이 아니라 사용자의 선택을 줄이는 방식으로 풀며, 보안 패치 설치가 자동화되어 사용자에게 그 선택이 더는 제시되지 않는다

요지 Main idea

컴퓨터 보안의 근본적 딜레마는 사람들이 보안을 원하지만 자신의 보안을 평가하거나 개선할 결정을 내릴 준비가 제대로 되어 있지 않다는 것이다. 사용자를 교육해 이를 해결하려는 시도는 대체로 성공하지 못했으므로, 사용자가 더 나은 선택을 하도록 돕기보다 선택을 단순히 줄이는 편이 낫다고 글은 말한다. 엘리베이터 버튼처럼 기술은 작동에 필요한 측면만 노출하고 사용자를 위험에 빠뜨릴 수 있는 결정을 요구하지 않아야 한다. 한 유명 IT 기업은 이 철학을 받아들였고, 최근에는 운영 체제에서 보안 패치 설치를 자동으로 만들었다. 따라서 그런 컴퓨터를 쓰는 사람에게 보안 패치를 설치할지 말지의 선택은 더는 제시되지 않는다는 ①이 빈칸에 알맞다.

쉬운 설명

컴퓨터 보안에서는 사람이 어려운 결정을 직접 내리게 하기보다 아예 결정할 거리를 줄이는 게 낫다는 글이에요. 엘리베이터에서 버튼을 잘못 누를까 봐 걱정하지 않는 것처럼요. 보안 패치 설치가 자동이 되었으니, 설치할지 말지 고르는 일은 이제 사용자에게 주어지지 않아요.

글의 설계도

문제 제기 → 해결 방향(선택을 줄이기) → 비유와 원칙 → 사례 → 결론(빈칸)

빈칸 문장은 마지막 문장 the choice of whether to install a security patch ＿＿＿입니다. 빈칸에는 바로 앞 7번 문장(making the installation of security patches automatic)의 결과가 들어갑니다. 자동으로 설치되므로 설치 여부의 선택은 사용자에게 더는 주어지지 않는다는 뜻이며, 이는 3번의 it is better to simply reduce their choices와도 이어집니다.

1

The fundamental dilemma of computer security describes how people want security but are ill-equipped to make the decisions that would enable them to assess or improve their security.

★ 문제 확인ill-equipped to make the decisions: 사람들은 보안에 관한 결정을 내릴 준비가 제대로 되어 있지 않습니다.
해석

컴퓨터 보안의 근본적 딜레마는, 사람들이 보안을 원하지만 자신의 보안을 평가하거나 개선할 수 있게 해 줄 결정을 내릴 준비는 제대로 되어 있지 않다는 상황을 설명한다.

쉬운 설명

컴퓨터 보안의 근본적 딜레마는, 사람들이 안전하길 바라면서도 안전을 따지고 높일 결정을 내릴 준비는 잘 되어 있지 않다는 거예요.

내용 해설

문제 제기입니다. 보안을 원하는 마음과 필요한 결정을 내릴 준비 사이의 어긋남이 글의 출발점입니다.

문법·구문
  • describes how people want security but are ill-equipped ...: how가 이끄는 명사절이 describes의 목적어이며, want와 are ill-equipped이 but으로 병렬됩니다.
  • the decisions that would enable them to assess or improve ...: 주격 관계대명사 that이 decisions를 꾸미고, enable + 목적어 + to부정사 구조입니다.
2

해석

쉬운 설명

사용자를 교육해서 이 딜레마를 풀어 보려는 시도는 대체로 성공하지 못했어요.

내용 해설

기존 접근의 한계입니다. 교육을 통한 해결이 대체로 성공하지 못했다고 하며 다음 문장의 새 방향을 준비합니다.

문법·구문
  • Attempts to solve ... have largely been unsuccessful: 주어 Attempts는 복수이고 동사는 현재완료 have been입니다. to부정사구 to solve ...가 Attempts를 뒤에서 꾸밉니다.
  • by training users: 전치사 by 뒤에 동명사가 왔습니다.
3

★ 정답 근거it is better to simply reduce their choices: 사용자의 선택을 줄이는 쪽이 낫다는 글의 방향입니다.
해석

그래서 사용자가 더 나은 선택을 하도록 도우려 하기보다는, 그들의 선택을 단순히 줄이는 편이 낫다.

쉬운 설명

내용 해설

정답 근거 ①입니다. 글의 해결 방향이 ‘선택을 줄이는 것’임을 밝힙니다. 빈칸의 ‘선택이 제시되지 않는다’와 방향이 같습니다.

문법·구문
  • rather than attempting to ...: rather than 뒤에 동명사가 와서 ‘~하기보다는’의 뜻을 만듭니다.
  • it is better to simply reduce their choices: 가주어 it과 진주어 to부정사 구조입니다.
4

When people enter an elevator, they do not worry that pushing the wrong button will send them plummeting to their death.

! 해석 주의엘리베이터 예는 사용자가 위험한 결정을 하지 않아도 되도록 설계되어 있다는 비유입니다. 이 비유는 빈칸의 ‘선택이 제시되지 않는다’는 방향과 이어집니다.
해석

사람들은 엘리베이터에 탈 때, 잘못된 버튼을 누르면 자신이 곤두박질쳐 죽게 될까 봐 걱정하지 않는다.

쉬운 설명

사람들은 엘리베이터를 탈 때, 버튼을 잘못 누르면 추락해서 죽을까 봐 걱정하지 않아요.

내용 해설

비유(예시)입니다. 위험한 결정을 사용자에게 맡기지 않는 설계의 예로 엘리베이터를 듭니다.

문법·구문
  • they do not worry that pushing the wrong button will send ...: worry의 내용을 that절이 설명하며, 동명사구 pushing the wrong button이 그 절의 주어입니다.
  • send them plummeting to their death: send + 목적어 + 현재분사 구조로 ‘~가 곤두박질치게 하다’입니다.
5

A technology should expose only those aspects that allow the user to operate it and not require the user to make decisions that can endanger themselves and others.

★ 정답 근거not require the user to make decisions that can endanger themselves and others: 사용자를 위험에 빠뜨릴 수 있는 결정을 요구하지 말아야 한다고 했습니다.
해석

기술은 사용자가 그것을 작동할 수 있게 해 주는 측면만 드러내야 하고, 사용자 자신과 타인을 위험에 빠뜨릴 수 있는 결정을 사용자에게 요구하지 않아야 한다.

쉬운 설명

기술은 사용자가 쓸 수 있게 해 주는 부분만 보여 주고, 자신과 남을 위험하게 할 수 있는 결정은 사용자에게 시키지 말아야 해요.

내용 해설

정답 근거 ②입니다. 위험한 결정을 사용자에게 요구하지 않아야 한다는 원칙으로, 빈칸이 선택의 제거 쪽임을 뒷받침합니다.

문법·구문
  • should expose ... and not require ...: 조동사 should에 두 동사구가 and로 이어집니다.
  • aspects that allow the user to operate it: 주격 관계대명사 that이 aspects를 꾸미고, allow + 목적어 + to부정사 구조입니다.
  • decisions that can endanger themselves and others: 주격 관계대명사 that이 decisions를 꾸밉니다.
6

A famous IT company embraced this philosophy to good effect with their strategy of "secure by design and secure by default."

★ 사례 도입secure by design and secure by default는 설계 단계부터, 그리고 기본값으로 안전하게 한다는 전략입니다.
해석

쉬운 설명

내용 해설

문법·구문
  • to good effect: ‘좋은 효과를 거두며’라는 뜻의 관용적 표현입니다.
7

In recent years, the company has continued to lead the way by making the installation of security patches automatic in their operating system products.

★ 정답 근거making the installation of security patches automatic: 보안 패치 설치를 자동으로 만들었다는 것이므로, 사용자가 설치 여부를 고를 일이 없어집니다.! 해석 주의automatic을 ‘사용자가 하지 않아도 설치된다’로 읽지 않고, 설치가 자동이면 사용자가 늦추는 일이 생긴다고 오해하면 ②에 끌립니다. 자동 설치는 사용자의 행동을 기다리지 않는 방식이므로 ②의 ‘사용자의 무반응으로 지연된다’와 맞지 않습니다.
해석

쉬운 설명

최근 몇 년 동안 그 기업은 운영 체제에서 보안 패치 설치를 자동으로 하게 만들어서 계속 앞서 나갔어요.

내용 해설

빈칸 직전의 근거입니다. 패치 설치가 자동이 되었다는 사실이 마지막 문장의 결과를 결정합니다.

문법·구문
  • has continued to lead the way: 현재완료이며, continue to + 동사원형 구조입니다.
  • by making the installation ... automatic: by + 동명사이고, make + 목적어 + 형용사(5형식) 구조입니다.

문제 제기 (1-2)

사람들은 보안을 원하지만 결정을 내릴 준비가 제대로 되어 있지 않고, 사용자 교육은 대체로 성공하지 못했다.

해결 방향 (3)

사용자가 더 나은 선택을 하도록 돕기보다 선택을 줄이는 편이 낫다.

비유와 원칙 (4-5)

엘리베이터처럼 기술은 작동에 필요한 측면만 노출하고 위험한 결정을 사용자에게 요구하지 않아야 한다.

사례와 결론 (6-8)

한 IT 기업이 보안 패치 설치를 자동으로 만들어, 사용자에게 설치 여부의 선택이 더는 제시되지 않는다.

엘리베이터 버튼

엘리베이터에서는 버튼 하나를 눌러도 위험하지 않게 만들어져 있어서, 우리는 무엇을 눌러야 안전한지 따로 공부하지 않아요.

정답과 오답 분석

② is often delayed due to user inaction7번 문장에서 설치를 자동으로 만들었다고 했으므로 설치가 사용자의 행동에 달려 있지 않습니다. 사용자가 아무것도 하지 않아 설치가 지연된다는 말은 자동화의 취지와 맞지 않습니다.

수업 팁

빈칸 문장의 직전 문장(7번)이 빈칸의 원인이 되는지 확인하게 하세요. 설치가 automatic이면 선택이 어떻게 되는지 한 줄로 말해 보게 하세요.

조건 영작

rather than을 사용하여 ‘사용자가 더 나은 선택을 하도록 도우려 하기보다는, 그들의 선택을 줄이는 편이 낫다’를 영작하시오. (help, users, make better choices, reduce, better)

모범 답안: Rather than attempting to help users make better choices, it is better to reduce their choices. 채점 포인트: ① rather than 뒤에 동명사 형태(attempting 또는 trying)로 ‘~하기보다는’을 표현 ② it is better to + 동사원형으로 ‘~하는 편이 낫다’ 표현 ③ help users (to) make better choices. help 뒤의 to 유무, simply 같은 부사는 문제가 지정하지 않았으므로 자유입니다.
