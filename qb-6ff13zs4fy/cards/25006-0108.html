정답①

주제 Topic

적절한 응답: 팀장이 새 전화번호를 몰라 링크를 못 받을까 걱정하는 여자를 도와주는 남자

요지 Main idea

폭설로 동아리 모임이 온라인으로 바뀌었는데, 팀장이 자신의 새 전화번호를 몰라 문자로 보낼 링크를 받지 못할까 여자가 걱정하자, 남자가 링크를 받으면 자신이 문자로 보내 주겠다고 안심시킵니다.

쉬운 설명

눈이 많이 와서 모임이 온라인으로 바뀌었어요. 팀장이 새 번호를 몰라 링크를 못 보낼까 걱정하자, 친구가 받으면 문자로 보내 주겠대요.

논리 흐름

소식 전달

Irwin이 폭설 때문에 오늘 동아리 모임이 온라인으로 바뀐다고 알립니다.

링크 확인

Mia가 링크가 있는지 묻고, Irwin은 아직 오지 않았다고 합니다.

문제 제기

팀장이 2시까지 문자로 링크를 보낼 텐데, 팀장이 Mia의 새 번호를 모른다고 합니다.

해결

Irwin이 링크를 받으면 문자로 보내 주겠다고 안심시킵니다.

정답과 오답 분석

② That’s too bad. The online meeting is already over.That’s too bad. The online meeting is already over.는 ‘온라인 모임이 이미 끝났다’는 뜻입니다. 19번에서 모임은 오후 2시 30분이라고 했고, 아직 시작 전입니다.
③ Sure. I’ll log on to the website and host the meeting.Sure. I’ll log on to the website and host the meeting.은 ‘내가 웹사이트에 접속해 모임을 진행하겠다’는 뜻입니다. 여자의 걱정은 팀장이 새 번호를 몰라 링크를 못 받는 것(21번)이며, 남자가 모임을 진행한다는 말은 대본에 없습니다.
④ Terrific! I’m so proud of you for leading the meeting.Terrific! I’m so proud of you for leading the meeting.은 ‘모임을 이끌어서 자랑스럽다’는 뜻입니다. 여자가 모임을 이끈다는 내용은 대본에 없고, 22번은 도움을 청하는 질문입니다.
⑤ You don’t have to do that. They already sent the text message.You don’t have to do that. They already sent the text message.는 ‘그럴 필요 없다. 이미 문자가 왔다’는 뜻입니다. 17번 It hasn’t been sent yet.에서 링크는 아직 오지 않았다고 했으므로 사실과 어긋나고, 여자의 질문에도 답이 되지 않습니다.
① Don’t worry. I’ll text you the link when I get it.여자는 21번에서 팀장이 자신의 새 번호를 모른다고 하고 22번에서 What should I do?라며 도움을 청합니다. 남자가 Don’t worry.로 안심시키며 링크를 받으면 자신이 문자로 보내 주겠다고 답하는 것이 문제 해결로 이어지는 가장 적절한 응답입니다.

수업 팁

도움을 청하는 질문(What should I do?)의 응답은 문제를 해결해 주는 구체적인 행동 제안이 어울립니다.

링크가 ‘이미 왔다’, 모임이 ‘이미 끝났다’처럼 대본의 사실(17번, 19번)과 어긋나는 선지는 오답입니다.
